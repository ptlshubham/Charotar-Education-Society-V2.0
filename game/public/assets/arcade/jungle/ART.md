# Jungle artwork

Created with the built-in image generation tool using the team's jungle references. Original generated PNG bytes and transparency are preserved. The browser assembles animation frames into cached sheets; see `src/platformer/sprites.ts` for source dimensions and frame order.

The jungle level uses the new explorer, snail, macaw, gold coin, terrain, props, items, and waterfall backdrop, all in this folder. Other environments keep their existing characters and coins under `../shared/` until their own artwork is approved. Supplementary items are available for future gameplay; their appearance does not add power-up mechanics.

## player.webp

Use case: stylized-concept. Asset type: production transparent PNG sprite sheet for a jungle side-scrolling student adventure game. Match the attached reference's charming richly shaded hand-painted pixel-art explorer, warm brown outlines, tan safari hat, brown boots, khaki shirt, small backpack, friendly child adventurer. Create ONE sprite sheet, exactly seven equal columns and one row, no gutters, no labels or text, transparent background with genuine alpha. Each cell has the same character scale and ground baseline, full body facing RIGHT, feet centered horizontally, generous transparent margin. Frame order left to right: idle standing; running left leg forward; running passing pose; running right leg forward; jumping upward; falling with arms out; happy arms-raised victory. Wide canvas aspect ratio 21:4, intended final sheet 672 by 128, seven cells 96 by128. Character must stay entirely within its own cell. Consistent silhouette and costume all seven frames. Distinct animation poses, readable at small game resolution, crisp edges. No scenery, floor, drop shadow, interface, frame boxes or checkerboard painted into the image. This is a new original game character inspired by the jungle reference.
